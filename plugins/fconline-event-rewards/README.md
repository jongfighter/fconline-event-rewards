# FC Online Event Rewards

FC 온라인 공식 웹 이벤트, 웹상점, 멤버십 보상을 확인하고 수령하는 스킬입니다. 이벤트 코인으로 진행하는 미니게임도 현재 조건을 확인해 진행합니다.

- 호스트의 브라우저와 웹 검색 도구가 필요합니다.
- 로그인 상태가 아니고 아이디·비밀번호가 비어 있으면 대신 입력하지 않고, 브라우저 로그인 화면에 사용자가 직접 입력하도록 요청한 뒤 기다립니다.
- 게임 보관함 아이템 개봉은 `fconline-items-manager`의 범위입니다.

설치 방법과 로그인 동작은 [저장소 README](../../README.md)를 참고하세요.
