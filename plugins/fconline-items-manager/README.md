# FC Online Items Manager

> **운영정책 위험 경고**
> 이 플러그인의 `scripts/game_ui.py`는 실행 중인 FC ONLINE 창을 캡처하고 Win32 `SendInput`으로 마우스·키 입력을 보냅니다. 게임 메모리나 패킷은 건드리지 않지만, 넥슨 운영정책의 자동 프로그램·매크로 규정에 해당해 계정이 제재받을 수 있습니다. 사용 여부와 그 결과의 책임은 사용자에게 있으며, 위험을 받아들일 때만 설치하세요.

실행 중인 FC ONLINE 게임 화면에서 아이템 보관함 수령, 박스·카드 개봉, 쏠돌코인·교환 재료 소진과 BP 전환을 처리하고, 요청된 경우 공식경기 감독모드를 시작하는 스킬입니다. 웹 이벤트 보상만 받으려면 `fconline-event-rewards`를 쓰세요.

- Windows와 Python, Pillow가 필요합니다.
- 박스·카드 개봉은 사용자가 요청했을 때만 합니다. 유료 구매, 선수 매각·강화, 상자 삭제는 별도로 요청하지 않으면 하지 않습니다.
- 캡처 이미지는 기본적으로 `~/FCOnline/skill-ui-captures`에 저장됩니다. 닉네임·보유 재화 등이 보일 수 있으니 공유 전에 확인하세요.

설치 방법은 [저장소 README](../../README.md)를 참고하세요.
