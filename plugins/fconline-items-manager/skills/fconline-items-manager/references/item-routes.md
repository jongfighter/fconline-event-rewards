## 교환 경로 조사

- 전체 아이템 목록의 마지막까지 확인한다. 새 보상을 받은 후 최신순 위치가 바뀔 수 있다.
- 에이전트의 의뢰 타입 필터는 탭을 바꿔도 남아 있을 수 있다. 의뢰가 없다고 판단하기 전에 필터를 해제하고 관련 탭의 전체 목록을 확인한다. 분류는 산출 보상 기준일 수 있어 BP/선수팩을 주는 토큰 소비 의뢰가 `코인, 토큰` 필터에 없을 수 있다.
- 투입 화면에서 재료 부족이나 반복 한도를 확인한 뒤, 취소하면 투입 선택만 취소됐는지 잔량으로 확인한다. 실소비는 최종 진행 확인 이후다.
- 종료 여부는 정확한 공식 공지와 실제 날짜로 확인한다. 공식 공지 `n4ArticleSN=6226`은 `[2500만 BP 찬스] 파이널 쇼다운 보너스 쿠폰`의 과거 확인 경로다: <https://m.fconline.nexon.com/news/notice/view?n4ArticleSN=6226>. 같은 이름의 다른 차수·재발행이 있는지 현재 툴팁과 대조한다.
- 공식 근거가 없다면 `현재 전체 목록에서 찾지 못함`처럼 관찰 범위를 적는다. `대상 선수가 없음`은 토큰 단독 교환 불가 또는 선수 조건에 대한 근거이며 모든 소비처 종료를 증명하지 않는다.

## 소진 계획과 마감

현재 자원만으로 가능한 교환을 먼저 처리한다. 예를 들어 80개를 소진할 때 당시엔 60개 상품과 10개 상품 2개로 나눴다. 이 조합을 고정 최적안으로 삼지 말고 현재 보상·최소 단위·사용자 목표를 비교한다.

BP 전환이 목적이어도 이미 개봉해 나온 선수의 매각은 별도 실행 범위다. 선수팩 평가액·기준가와 실제 받은 BP를 혼동하지 않는다. 교환으로 나온 랜덤 CP 카드의 상한을 확정 보상으로 보고하지 않는다.

완료 기록은 `품목/시작량/실제 사용량/잔량/소비처/완료 근거 또는 미소진 조건`으로 남기면 재시작 시 중복 실행을 줄일 수 있다. 같은 날 파일을 갱신할 때도 과거 관찰을 지우지 말고 새 확인 시점을 적는다.
