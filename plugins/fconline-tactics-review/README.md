# FC Online Tactics Review

현재 FC 온라인 스쿼드·팀 전술·개인 전술·코치를 확인하고, 공격 전개·침투·수비 전환 문제의 개선안을 `현재 설정`과 `개선안`을 나란히 비교하는 HTML 조언판으로 작성하는 스킬입니다.

- 호스트의 브라우저 도구가 필요합니다. 공식 스쿼드메이커 조회에는 넥슨 로그인이 필요하며 로그인은 직접 해야 합니다.
- 분석만 요청하면 주전·코치·전술을 바꾸지 않습니다. 게임에 실제로 적용하는 일은 별도로 요청해야 합니다.
- 결과 HTML에는 선수·팀 정보가 들어가므로 공유 전에 확인하세요.

설치 방법은 [저장소 README](../../README.md)를 참고하세요.
