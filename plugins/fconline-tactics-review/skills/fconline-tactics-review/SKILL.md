# FC 온라인 전술 분석·HTML 조언판

## 현재 상태부터 확인

- `A/B/C 스쿼드`와 각 스쿼드 안의 전술 슬롯을 구분한다. 사용자가 스쿼드를 정정하면 그대로 따르고 같은 이름의 전술 슬롯으로 다시 해석하지 않는다.
- 브라우저 도구로 직접 봐 달라는 요청이면 로그인된 공식 스쿼드메이커의 `게임 정보 불러오기` 등 현재 확인 가능한 경로를 사용한다. 로그인이 필요한데 넥슨 로그인 화면의 아이디·비밀번호 입력란이 비어 있으면 대신 입력하거나 채팅으로 받지 말고, 사용자가 브라우저에서 직접 입력하도록 요청하고 기다린다. 입력값은 응답·기록에 옮기지 않고 채워졌는지만 값 길이의 참·거짓으로 확인한다. 로그인 폼이 열려 있는 동안에는 스냅샷·스크린샷·텍스트 찾기·네트워크 요청 본문 조회와 값을 반환하는 평가·콘솔·네트워크 로그를 쓰지 않는다(비밀번호 칸 값이 그대로 노출될 수 있고, 도구가 스냅샷 파일을 자동 저장하니 그 파일도 열지 않는다). 로그인이 끝나면 이번 로그인 창 동안 자동 저장된 `.playwright-mcp/page-*.yml`만 이름을 지정해 입력값이 남았는지 값은 출력하지 않고 개수로 확인한다(PowerShell `@(Select-String -LiteralPath <파일> -Pattern 'textbox .*\]:\s*\S').Count`, 다른 셸 `grep -cE 'textbox .*\]:[[:space:]]*[^[:space:]]' <파일>`). 0이 아니거나 내용을 확인할 수 없는 스크린샷 파일은 사용자에게 알린 뒤 삭제하고, 폴더째 삭제하거나 이전 파일을 건드리지 않는다. 로그인 화면 주소는 `hostname`이 `nexon.com`이거나 `.nexon.com`으로 끝날 때만 신뢰한다. 추가 인증은 사용자가 직접 완료한다. 게임 적용·감독모드 확인이 필요하면 게임 화면에서 별도로 확인한다.
- 선수 위치·시즌·강화, 포메이션, 공격/수비 스타일·폭·깊이·박스 숫자·세트피스 숫자, 개인 지시와 참여도, 코치 구성을 현재 값으로 확보한다. 과거 문서보다 최신 조회가 우선한다.
- 사용자가 이미 제공했거나 직접 조회할 수 있는 값을 다시 모두 적어 달라고 요구하지 않는다. 영상 없이 관찰할 수 없는 움직임·실점 원인은 사용자 증상과 설정에 근거한 가설로 표시한다.

## 진단과 수정안

- 공격이 막히는 구간, 침투·크로스 타깃, 공을 잃는 순간의 중원 보호 등 사용자가 지적한 현상에 답한다. 확인한 설정 → 가능한 원인 → 비교할 수정 → 예상 부작용을 연결한다.
- 주전 구매·포메이션 전면 교체를 자동 전제로 하지 않는다. 현재 구성을 활용한 우선순위 있는 수정안을 제시하고 한 번에 비교 가능한 변화량으로 정리한다.
- 최신 메타·선수 성능·전술 지시 의미·유튜버 분석을 주장할 때는 현재 공식 자료나 실제 자료를 확인한다. 유튜버 분석을 요청하면 실제 영상/발언·게시 시점과 해당 팀에 적용되는 이유를 연결하고 링크한다. 보지 않은 영상을 봤다고 하지 않는다.
- 예측을 승률 보장처럼 표현하지 않는다. 실제 경기 증거와 설정에서 추정한 원인을 구분한다.

## HTML 산출물 필수

- 분석·개선안은 **HTML 파일로 완성**하고 최종 답변에서 HTML 파일 링크를 먼저 준다. 채팅 설명이나 Markdown 문서만으로 끝내지 않는다.
- 기존 게임 전술 화면 형태의 조언판이 있으면 그 형식을 이어가며 `현재 설정`과 `개선안`을 나란히 비교할 수 있게 한다. 과거 선수·슬롯·수치를 그대로 복사하지 않는다. [로컬 자료와 검증](references/local-artifacts.md)을 참고한다.
- 사용자가 저장 위치를 지정했다면 그 위치를 쓴다. 지정이 없으면 현재 작업 폴더에 저장하고, 거기에 기존 산출물이 있으면 이어간다.
- 팀 전술 수치, 개인 전술·참여도, 선수 배치, 바꿀 순서와 비교 기준, 근거 링크를 담는다. 코치 제안이 있으면 정확한 특성명과 현재 역할을 확인한다.
- 로컬 브라우저에서 실제 렌더링을 확인해 잘림·겹침과 PC/모바일 가독성을 점검한다. 정적 설명만 바뀌는 작업에 불필요한 테스트 코드를 추가하지 않는다.

## 분석과 실제 적용 구분

웹 보관함에 저장한 스쿼드·전술을 인게임 적용 완료라고 말하지 않는다. 사용자가 실제 적용을 요청했다면 지원되는 게임 UI에서 반영하고 같은 스쿼드·슬롯의 값이 바뀌었는지 확인한다. 게임 조작이 필요하면 `fconline-items-manager` 스킬을 쓸 수 있으면(플러그인이든 직접 설치한 스킬이든) 그 스킬의 게임 조작 참고와 권한 진단 절차를 활용하고, 없으면 사용자가 직접 적용하도록 안내한다. 분석만 요청한 경우 주전·코치·전술을 임의 변경하지 않는다.
