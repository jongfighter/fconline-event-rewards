# 기존 자료와 HTML 검증

## 기존 형식 찾기

사용자가 지정한 작업 폴더(없으면 현재 작업 폴더)에서 `rg --files`로 지금 존재하는 HTML·템플릿·조회 자료를 찾는다. 찾은 파일은 읽기 전에 날짜와 내용을 확인하고, 현재 조회 결과보다 우선하지 않는다.

- 게임 전술 화면 형태의 조언판 HTML이나 템플릿이 있으면 그 구조를 이어간다.
- 수비 전환·공격 전개 개선안 같은 과거 문서는 증상과 제안의 참고일 뿐이다. 그 파일만 고쳐서 완료하지 않는다.
- 이전 스쿼드·팀 전술·코치 조회 자료가 있어도 현재 값으로 쓰지 않고 다시 조회한다.
- 기존 조언판이 없으면 `현재 설정`과 `개선안`을 나란히 비교하는 구조로 새로 만든다.

기존 검증 스크립트를 사용할 수 있지만 실행 전 어떤 파일을 읽고 쓰는지 확인한다. 파일 이름이나 현재 값에 종속된 오래된 검증을 성공 근거로 그대로 쓰지 않는다.

## 분석에서 구분할 것

- 스쿼드 선택 A/B/C와 전술 슬롯 이름은 다른 축이다.
- 웹 스쿼드메이커 보관함 저장과 게임에 실제 적용은 다른 작업이다.
- 팀전술의 숫자와 개인 지시 코드는 의미가 다르다. 현재 UI의 한국어 이름과 코드가 대응하는지 확인한다.
- 후방 대기 지시는 공격 시 행동이며 수비 시 위치 고정을 보장하지 않는다. 침투·수비 지원·차단·참여도를 함께 보고 사용자가 지적한 상황과 연결한다.
- 특정 센터백 설정이 원인이라고 가정하기 전에 실제 현재 설정을 확인한다. 영상 없는 상황에서 조작 습관을 단정하지 않는다.
- 특정 선수의 역할 제안은 실제 위치·주발·강화·현재 코치와 맞춘다. 예전 템플릿에 있던 선수 구성을 그대로 설명하지 않는다.

## 결과물 확인

현재/추천 수치가 표·전술 화면·설명 사이에서 일치하는지 확인한다. HTML을 열어 실제 PC와 좁은 화면에서 확인하고 설명이 카드 위에 겹치거나 잘리지 않게 한다. 인터랙션을 넣었다면 비교 전환·선수 선택 등의 실제 동작을 확인한다.

최종 답변 첫 링크는 완성된 로컬 HTML로 연결하고 중요한 변경점과 미검증 한계만 짧게 덧붙인다. 사용자가 직접 적용해야 하는 상태라면 그것을 명확히 말한다. 조언판에는 사용자의 선수·팀 정보가 들어가므로 공유 전에 확인하도록 안내한다.
